# Customer Segmentation for Speedy Loans

## Business Problem
Speedy Loans needed to understand their customer base to create targeted marketing campaigns and better risk assessments.

## My Approach
- Applied K-Means clustering to group customers
- Tested different distance metrics (Euclidean, Manhattan, Correlation)
- Used complete-linkage clustering for best results

## Key Findings
| Cluster | Profile | Business Insight |
| :--- | :--- | :--- |
| **0** | Young, low-income, high debt | High risk; require stricter terms |
| **1** | Older, high-income, long tenure | Low risk; ideal for premium products |
| **2** | Affluent, established | Very low risk; suitable for credit increases |

## Technologies Used
- Python (Scikit-learn, Pandas)
- Tableau for visualization
